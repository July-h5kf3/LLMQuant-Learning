## 当前内容

### `LISA/`

`LISA/` 目录用于复现 LISA（Large Language Instructed Segmentation Assistant）相关方法，目前已经完成初步复现，包含：

- 基于当前环境整理后的训练与测试脚本
- LISA 主体模型实现，以及与 LLaVA、SAM 相关的依赖代码
- 数据处理、数据集封装与配置文件
- 复现过程中的说明文档与问题记录

当前阶段的工作重点是继续在已有初步复现的基础上，补充验证、整理实验结果，并为后续量化相关实验做准备。

后续如果增加新的模型复现或实验代码，也会继续放在这个目录下统一管理。
